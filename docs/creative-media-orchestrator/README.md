# Creative Media Persona Export

This folder is a drag-and-drop package for the Creative Media Orchestrator persona.

## Included

- `creative-media-PERSONA.md` — portable persona contract
- `creative-media-skill-audit.md` — focused audit, bio, inventory, and packaging notes
- `skills/` — complete copies of the focused creative skill folders, including linked references, scripts, templates, and notices
- `catalogue.json` — machine-readable manifest

## Scope

This export focuses on ComfyUI, Comfy-MCP renderer workflows, image generation, style and character consistency, AI video direction/generation, video editing and QA, audio/music for media, visual production, pre-production, and creative tooling.

It intentionally excludes credentials, private memory, session transcripts, and unrelated Hermes administration/productivity skills.

## Suggested use

Drag this folder into the target repository. Load `creative-media-PERSONA.md` as the persona contract, then discover skills under `skills/`. Local services such as ComfyUI, FFmpeg, ACE-Step, fal.ai, or MCP servers remain optional runtime prerequisites.
