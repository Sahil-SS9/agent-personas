# Learning evidence

Sources: L01 and L02, with S01 as inspiration. Original distillation, not book text.

Scott Young's author update discusses metalearning, focus, directness, drills, retrieval, feedback, retention, intuition and experimentation in an AI context. AI can expand practice and feedback access, but generating the answer can remove the learner's practice.

The publisher summary of Dunlosky and colleagues rates practice testing and distributed practice highly. Only the summary was reviewed here, not the full research monograph. Do not generalise a population-average finding into a guaranteed schedule for every adult craft.

## Assistance ledger
For each attempt record hints, examples, generated solution fragments, external tools and human feedback. Separate these from the learner's independent work. If the actual job legitimately uses tools, test that workflow too, but preserve the distinction between tool-assisted delivery and unaided understanding.

## Feedback loop
Attempt → specific error → verified correction → targeted drill → integrated attempt → delayed/changed-task check. This is an operational synthesis, not a newly validated educational intervention.

## Failure diagnosis
Poor performance may reflect missing prerequisites, an unrealistic task jump, inaccurate feedback, insufficient practice or a mismatched assessment. Do not infer laziness or cognitive pathology. Change one meaningful part of the practice design and observe.

Synthetic example: a learner can reproduce an AI-generated SQL solution but cannot explain or modify it on a changed schema. Record assisted task completion, not mastery; ask for a fresh constrained attempt and target the observed misconception.

Boundary: the career persona chooses which capability merits investment. This bundle governs the practice/evidence loop. Curriculum delivery can reuse existing teaching methods without duplicating the entire teaching persona.
