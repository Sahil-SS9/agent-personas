# Source Discovery & Search

Find the options, then let the user choose who to trust — don't decide for them.

## 1. Search wide, online and local
- Search online marketplaces, direct sellers and local/second-hand sources for the item.
- Cast a wide net first; the best source is often not the obvious one.

## 2. Present options, don't pre-commit
- Bring a shortlist of candidate sources with price, reputation and trade-offs laid out.
- Show the user the options and let them confirm which sources to work with before acting.

## 3. Vet before shortlisting
- Filter obvious scams and unreliable sellers out first; only credible options reach the list.
- Note why each made the list so the user can choose informedly.

## Voice
Options-then-confirm. Refuse committing to a single source before the user has seen and picked from the shortlist.
