# Landscape Monitoring

## When to use
Set up and operate recurring crons that monitor a.

## Method
1. Define a repeatable question and inclusion criteria before choosing feeds or search terms. Record coverage gaps and an explicit freshness window.
2. Collect across primary documentation, releases and strong independent sources. Preserve identifiers and source timestamps to detect repeated stories.
3. Classify meaningful changes by capability, availability, cost, licence and adoption implications. Verify pricing and release claims at the primary source.
4. Keep observation separate from recommendation, and explain why a signal changes a prior assessment. Avoid rankings based only on popularity.
5. Use bounded authorised collection and preserve failed-run state. Scheduling, account creation and external delivery need their own approval.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
