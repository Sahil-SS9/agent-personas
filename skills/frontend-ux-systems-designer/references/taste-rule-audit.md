# Inherited anti-slop rule audit

Source: installed design-taste-frontend v2.0.0, inspected in this session. Its live file is unchanged. Findings below govern reuse in this candidate only; do not load that entire skill as an unquestioned dependency.

## Retain as correctness or evidence requirements
Semantic labels, keyboard operation, visible focus, contrast, motion preference handling, responsive checks, cleanup, content honesty, explicit actual-versus-placeholder evidence and rendering the real result.

## Replace rigid aesthetics with contextual judgement
- One accent, no serif defaults, prohibited palette families and fixed hero geometry: replace with a brief-derived token/composition rationale. Brand identity can legitimately need several colours, serif typography or long-form introductions.
- Forced imagery and rejection of all text-led pages: choose imagery when it serves the task; an intentionally typographic editorial page can be complete.
- Every section must have a different layout: require appropriate rhythm, not gratuitous novelty. Repetition can improve navigation and comparison in product interfaces.
- Blanket centred-hero/card/gradient bans: flag unmotivated repetition, not the individual pattern. These elements are not evidence of AI authorship.
- React/Next/Tailwind defaults: inspect the actual environment; visual design is not a reason to migrate an established stack.
- One library versus arbitrary mixing: require coherent tokens, semantics, behaviour and technical compatibility rather than brand-count rules.
- Numeric variance/motion/density presets: use descriptive intent and observed outcomes; these values are not calibrated quality measures.

## Additional prototype recipe audit

The inherited design-build-prototype recipe contains blanket page-wide gradient/blending restrictions, a fixed minimum animation-layer count and an above-fold component quota. This candidate does not inherit those prescriptions. Keep reference verification, labelled demo content, working previews and user selection; choose compositing, motion and component count from the approved experience concept. More effects are not a substitute for art direction.

## Resolve contradictions explicitly
The inherited skill simultaneously warns against fake precision and suggests organic-looking numbers. Keep the stronger truth rule: real data or clearly labelled examples, never fabricated credibility. It contains broad contextual disclaimers alongside absolute bans; this candidate does not inherit those bans. Forced motion to satisfy a dial cannot override reduced-motion or the user's task.

## Replacement anti-generic review
Distinctiveness: do alternatives visibly differ beyond surface tokens?
Coherence: does the whole interface follow the selected visual and interaction language?
Brief fidelity: does it serve this audience/content/task and the user's expressed preference?
Functional quality: can users actually use it across required inputs/viewports?

Evidence must include rendered output and concrete observations. Do not issue a numerical slop score or promise eradication. Update examples from real user feedback; do not expand a blacklist after every disliked design.
