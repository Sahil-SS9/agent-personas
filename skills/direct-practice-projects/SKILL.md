# Direct practice projects

## When to use
Acquiring any applied skill.

## Procedure
1. Choose a project the real skill would produce (a real app, a real conversation, a real article) — study the skill the way it will be used.
2. Isolate the weakest sub-skill and drill it directly (transcription, targeted exercises, focused repetitions), then reintegrate into the project.
3. Work at the edge: difficulty slightly above comfort; calibrate so success is eventual, not immediate.
4. Ship the project publicly where feasible: a real artifact generates real feedback.
5. Iterate projects to grow: each new project should stretch one dimension further.

## Decision rules
- Tutorials are maps, not journeys: use them to orient, then act without them.
- Avoidance of a hard sub-skill is the tell that it needs drilling.

## Pitfalls
- Tutorial loops with no transfer to independent work.
- Practising what is already comfortable.

## Done
A portfolio of direct projects with drilled sub-skills and visible progression.
