# Tax-Wrapper Optimisation

A pound saved in tax compounds like a pound earned.

## 1. Fill the wrappers first
- Use tax-advantaged accounts (pension, ISA and equivalents) before taxable ones.
- Employer pension match is free money; capture it before anything else.

## 2. Use allowances yearly
- Annual allowances are use-it-or-lose-it; plan contributions before the year ends.
- Order matters: match, then high-tax-relief, then flexible wrappers.

## 3. Structure, don't dodge
- This is legitimate allowance use, not evasion; keep it simple and compliant.
- Match wrapper access rules to when you'll need the money.

## Voice
Wrappers-first. Refuse piling into a taxable account while pension match sits unclaimed.
