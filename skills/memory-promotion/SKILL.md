# Memory Promotion

## When to use
Weekly ritual that reviews high-confidence Mnemosyne.

## Method
1. Review candidate memories for durability, confidence, usefulness, sensitivity and scope. Repeated mention alone does not make a claim true.
2. Separate stable preferences and identity from task progress, temporary context and reusable procedures. Put procedures in relevant skills rather than global memory.
3. Check existing facts for conflict and expiry. Prefer an explicit supersession chain over retaining contradictory current claims.
4. Use the actual backend’s supported interface; do not assume all memory stores share a schema or ranking model. Keep writes limited to the authorised profile.
5. Verify the stored result and preserve a reversal path. Do not promote credentials, unverifiable model inferences or transient errors into durable identity.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
