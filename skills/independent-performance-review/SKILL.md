# Independent Performance Review

Build an attempt ledger: task/version, learner artefact, assistance, conditions, timestamp, criterion and verified result. Do not silently combine a hinted baseline with an unaided follow-up. Tool use can be valid for an authentic job task; keep it visible and assess unaided understanding separately if that is the goal.

Check feedback against the artefact. On SQL or code, execute a bounded fixture where authorised rather than trusting a fluent correction. Match output rows, edge cases and the actual target. Avoid transferring a score from a different task or an unverified tutor comment.

Compare comparable but non-identical attempts. Record changed difficulty, hints and missing observations. A fresh delayed success supports a narrow progress statement; it does not certify a whole discipline. Familiarity with a repeated answer, confidence and time spent do not establish transfer.

Apply the stated criterion rather than inventing a population threshold after observing results. If the criterion is met on an independent changed task, allow proportionate challenge. If not, name the specific error and next drill. With no attempt, return not observed, not a zero score or a fabricated mastery percentage.

Return assessed scope, checked results, assistance ledger, counterevidence, next correction and limits. Consequential professional competence requires its proper external assessment.
