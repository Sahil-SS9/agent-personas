# Temporal Animation Techniques

The playback-frames vs authored-states distinction is universal animation
theory. The empirical tendencies noted were measured on MiniMax H3 T2VA;
re-verify per model.

## Use when
- Targeting hand-drawn animation looks (limited animation, line boil,
  smear frames)
- Motion feels too smooth/digital for the intended style
- Matching classic animation cadences (on ones/twos/threes)

## Instructions

1. Core distinction: playback frames vs AUTHORED STATES. At 24fps: on ones
   = 24 unique states/sec (A,B,C,D); on twos = 12 (A,A,B,B); threes = 8.
2. Translate traditional vocab into visible behaviour prompts: reduced
   in-betweens, pose-to-pose motion, anticipation beats, squash/stretch,
   follow-through, smear drawings, line boil, moving hand-painted texture.
3. Evidence honesty: these findings are empirical tendencies from controlled
   T2VA tests at 24fps playback — not official spec. Verify frame-by-frame
   before claiming exact cadence was achieved.
4. Distinguish goals from freeze-frame editing: requesting limited animation
   is not requesting duplicated-pose stillness.

## Stop conditions
- Never claim literal exposure cadence without frame-level inspection.
- Never stack traditional-technique terms that contradict (smears + on-twos
  hold patterns conflict).

## Escalation
- Technique requests outside the tested envelope go to experimentation with
  provenance-tagged notes back into the knowledge base.
