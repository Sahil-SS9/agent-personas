# Visual hierarchy craft

## When to use
Every screen and component design/build.

## Procedure
1. Answer the teardown questions first: what is this page for, what is the primary action, what is noise? Design answers them visually.
2. Establish hierarchy: the most important element gets the most visual weight (size, weight, contrast, position); secondary content recedes. Uniform styling communicates nothing.
3. Use spacing as structure: proximity groups related elements, white space separates unrelated ones. Scale spacing deliberately (4/8/16/24/32...), don't nudge.
4. Colour with intent: limited palette + one accent is the DEFAULT, chosen for the brief's register — editorial, brand or event surfaces can earn a bolder range when the content supports it; contrast ≥4.5:1 for body text holds at every expressiveness level. Emphasis through weight and contrast, not rainbow.
5. Typography: 1-2 typefaces, deliberate scale with confident steps (bigger steps between hierarchy levels read as conviction), measure 45-75 characters body, line-height 1.4-1.6; optical alignment; display sizes may breathe far larger on editorial/brand surfaces (fluid endpoints beat breakpoint nudges).
6. Elevation/depth: shadows communicate layering consistently (one shadow system, not random).

## Decision rules
- If everything is emphasised, nothing is: force a visual priority list per screen.
- Alignment is a system: pick a grid and align everything to it; optical alignment for icons/text.
- Density follows the product register: tools compress, editorial breathes.

## Pitfalls
- Gradient/emoji/template slop as design.
- Grey-on-grey low-contrast text.
- Timidity treated as taste: restraint is a register decision, not an automatic virtue.

## Done
A screen whose hierarchy is legible in a 5-second glance, built on the shared token system.
