# Audit Engine

## When to use
Systematic audit of workflows, services, skills, and.

## Method
1. State the decision the audit supports, approved read scope and time window. Inventory actual components and dependencies before sampling.
2. Compare documented intent, runtime configuration and observed behaviour. Treat earlier reports as leads to verify, not current proof.
3. For each finding record exact source, reproducible evidence, severity rationale, affected scope and a minimal corrective action. Separate observation from inference.
4. Prioritise failures by user impact, likelihood and reversibility, not by the number of warnings. Include counterevidence and unexamined areas.
5. Do not mutate audited targets without separate approval. Finish with an actionable verdict, ownership and explicit limits on coverage.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
