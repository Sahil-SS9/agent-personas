# Retrieval and spacing design

## When to use
Any learning plan, from a language to a framework.

## Procedure
1. Define the competence concretely: what the learner can DO at the end (performance, not certificate).
2. Build retrieval into every session: recall from memory, solve, produce — before consulting notes. Passive review feels productive and isn't.
3. Space the reviews: increasing intervals (e.g. 1d, 3d, 7d, 14d) on a simple schedule or SRS tool; consistency over intensity.
4. Interleave related topics within sessions; blocked drilling feels smooth but transfers worse.
5. Track recall per item; hard items return sooner, mastered items recede.

## Decision rules
- If it feels easy, it is probably too easy: add desirable difficulty (closed-book, time pressure, harder variants) while keeping struggle productive.
- Cramming is for trivia, not competence.

## Pitfalls
- Highlighting and rereading as a study plan.
- Reviews crammed the night before the performance.

## Done
A spaced, retrieval-first schedule tracking recall per item.
