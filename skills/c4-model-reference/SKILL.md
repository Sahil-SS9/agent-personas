# C4 Model Reference

## When to use
Apply C4 component diagram concepts accurately.

## Method
1. Choose one C4 zoom level for a diagram: system context, containers, components or code. State audience and question before drawing.
2. At context level show the system, people and external systems; at container level show deployable applications and data stores; component views stay inside one container.
3. Use meaningful component responsibilities rather than treating every class or folder as a component. Label directed relationships with their purpose and relevant technology.
4. Include title, scope, key and legend. Distinguish logical boundaries from deployment nodes and avoid mixing abstraction levels.
5. Verify diagrams against actual dependencies and pair consequential decisions with records of alternatives and trade-offs. Reference: https://c4model.com/.
