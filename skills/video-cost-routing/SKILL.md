# Video Cost Routing

## When to use
Route video generation to the right model by budget, quality and latency needs.

## Method
1. Measure current cost per usable clip, including retries, electricity and operator effort. Do not use undated price examples.
2. Route inexpensive drafts first; compare representative clips before paying for final renders.
3. Obtain composition and budget approval before premium generation. Stop at the agreed spending limit.
4. Record actual cost, latency and usable-output rate; revisit routing when measured results change.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
