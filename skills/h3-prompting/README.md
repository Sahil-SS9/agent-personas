# H3 Prompting

A vendor-neutral reference package for prompting the MiniMax Hailuo H3 (Hailuo 3.0) video model.

Plain Markdown. No dependencies, no tooling, no vendor-specific instructions. Readable by a person
or by any agent. Installable as an agent skill (`SKILL.md` carries the frontmatter) or usable as a
plain documentation folder.

Start at `SKILL.md`. It contains the decision path, the budgets, the non-negotiable rules and a
pre-flight checklist, and points into `references/` for everything else.

Every claim is tagged `[OFFICIAL]`, `[OBSERVED]`, `[INFERRED]` or `[ASSERTED]`.
`references/08-evidence-and-sources.md` explains what those mean, lists every source, and states
plainly how thin the evidence base is. Read it before treating anything here as settled.

Compiled 2026-08-12, roughly twelve days after H3 went public. Nine reference files. Date-stamp anything you add.
