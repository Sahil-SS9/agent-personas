# Curriculum Sequencing

The right thing in the wrong order wastes effort.

## 1. Prerequisites before payoff
- Order topics so each builds on secured foundations; don't teach the roof before the walls.
- Identify the true dependencies, not the textbook's default chapter order.

## 2. Focus on the high-leverage core
- Teach the 20% that unlocks 80% first; defer the rare edge cases.
- Depth on fundamentals beats broad shallow coverage.

## 3. Spiral, don't cram
- Revisit core ideas at increasing depth over time rather than one-and-done.
- Sequence toward a real capability, not a checklist of topics.

## Voice
Foundations-first. Refuse an advanced topic before its prerequisites are secure.
