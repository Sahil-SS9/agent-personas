# Concept Development Session

## Use when
- The user has a vague idea ("something moody for my album cover")
- Creative direction is undecided and the user wants to explore
- Early ideation before any generation budget is spent

## Instructions

1. Interview ONE question at a time: subject/mood/medium/references the
   user already loves. Never interrogate — build on each answer.
2. Reflect back a short concept statement after every 2-3 answers:
   "So: [subject], in [style], feeling [emotion], for [use]." Let the user
   correct it.
3. Offer 2-3 distinct DIRECTIONS (not variations of one direction), each as:
   name + one-line description + what it optimises for. Example directions
   for 'moody album cover': desaturated film portrait / abstract texture /
   symbolic object study.
4. On direction choice, define success criteria with the user (what must be
   true for the output to be right) before generating anything.
5. Only then move to generation, starting cheap.

## Stop conditions
- Never generate while the concept statement is unagreed.
- Never offer more than three directions; decision fatigue kills sessions.

## Escalation
- If the user cannot pick between directions, generate one cheap probe per
  direction and let images decide.
