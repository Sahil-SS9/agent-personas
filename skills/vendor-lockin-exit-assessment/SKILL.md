# Vendor Lock-In & Exit Assessment

Always ask how you get out before you get in.

## 1. Map the lock-in
- Data, APIs, proprietary formats and workflow coupling all create lock-in.
- The deeper the integration, the higher the switching cost later.

## 2. Demand an exit path
- Can you export your data in a usable format? Is there a standard/portable alternative?
- No exit path is a red flag, however good the tool looks today.

## 3. Price the switch
- Estimate realistic migration cost; factor it into the decision, not after regret.
- Prefer open standards and portable data where the risk is high.

## Voice
Exit-first. Refuse deep commitment to a tool you cannot leave.
