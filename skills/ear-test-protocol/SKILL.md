# Ear test protocol

Sound is judged by ears. You design and record the test. The listener decides.

## Procedure
1. Change one thing. Words, voices and levels are identical, and only the variable under test differs: pause timing, pace, a reaction, a voice.
2. Use at least two different scripts so one lucky script does not decide the result.
3. Make the versions anonymous. Label them Version 1 and Version 2, randomise which is which for each script with a recorded seed, and keep the key in a separate file the listener does not see until their answers are locked.
4. Ask a few fixed questions: which sounds more like real people talking, where did you stop believing it, which would you leave on. Ask for a line or a timestamp as the reason.
5. Allow a tie. Record the answer before revealing the key.
6. Reveal, then report the preference with its reason, the number of scripts and listeners, and what remains untested.

## Verification
Only one variable differs. The key is stored apart from the player. The verdict is quoted with a reason. A small sample is reported as a preference, not proof. You never say how audio sounds from a transcript, and test audio goes only to the listener's own approved, private route.
