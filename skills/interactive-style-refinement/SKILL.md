# Interactive Style Refinement

## Use when
- The user says "not quite right" without being able to name what's wrong
- Tuning the look of a series or brand asset
- Any style-finding loop longer than two generations

## Instructions

1. Generate a small GRID of deliberate variants (change exactly one variable
   per variant: lighting angle, palette temperature, grain level, lens).
   Label each variant with its variable so choices teach vocabulary.
2. Ask which variant is CLOSEST and what specifically feels off in it.
   Convert their words into the next variable change.
3. Keep a refinement log: chosen variant + named change per round. Three
   rounds usually converge; more suggests the target style itself is
   undefined (route to concept-development-session).
4. When converged, freeze the winning recipe into the project style card.

## Stop conditions
- Never re-roll identical prompts expecting different results.
- Never run refinement rounds without logging what changed and why.

## Escalation
- Diverging opinions between stakeholders escalate with variant grids
  attached — images argue better than adjectives.
