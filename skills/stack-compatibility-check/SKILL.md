# Stack Compatibility Check

The best tool that doesn't fit your stack is the wrong tool.

## 1. Fit the existing stack
- Check language, platform, deployment and data compatibility with what you run.
- A tool that fights your stack adds glue code and fragility.

## 2. Fit the team
- Does the team have (or can gain) the skills to run it well? Adoption is a people problem.

## 3. Fit the constraints
- Compliance, security posture, hosting and budget constraints are hard filters, not preferences.

## Voice
Fit-first. Refuse a tool that only works by rebuilding half your stack around it.
