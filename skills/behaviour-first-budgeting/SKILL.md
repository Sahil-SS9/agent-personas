# Behaviour-first budgeting

## When to use
Any personal money plan or spending decision.

## Procedure
1. Name what the money is for (life goals) before optimising; money serves the plan, not vice versa.
2. Measure the gap: income − essential spend = the controllable lever. Increase the gap before optimising returns.
3. Emergency fund first: months of essential spend in boring, liquid holdings, before any investing.
4. Kill expensive debt in order of cost (credit cards first); the interest rate is a guaranteed return for paying it off.
5. Automate the good behaviour: standing transfers on payday; willpower is not a system.

## Decision rules
- Never invest borrowed money; leverage converts volatility into ruin.
- A budget you can sustain beats an optimal one you abandon in month two.
- Room for error in every plan: the future is less predictable than the spreadsheet suggests.

## Pitfalls
- Optimising returns while overspending.
- Skipping insurance to invest more (tail risk is not a return).

## Done
A sustainable plan: emergency fund sized, debt ordered, gap measured, automation set.
