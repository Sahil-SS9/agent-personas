# Skill Catalogue Audit

## When to use
Weekly audit of all skills (not just provisional).

## Method
1. Inventory logical skill names, versions, duplicate copies, references, ownership and last observed use. Distinguish active packages from archived evidence.
2. Check triggers, task boundaries, contradictory guidance, unresolved links, private assumptions, licensing and executable dependencies.
3. Measure utility with representative tasks and failures, not instruction length or a model-generated score. Separate structure, behaviour and comparative uplift.
4. Classify each package as keep, harden, consolidate, archive or internal-only, with a source-backed reason and the canonical version identified.
5. Do not delete or replace live skills during an audit. Verify corrections against the original task and preserve provenance.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
