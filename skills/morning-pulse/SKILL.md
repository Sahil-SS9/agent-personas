# Morning Pulse

## When to use
Summarise current commitments, blockers and priority decisions.

## Method
1. Read only the authorised project and commitment sources. Anchor the report to an explicit date and distinguish overdue items from stale records.
2. Identify urgent decisions, deadlines, blocked work and commitments at risk. Prefer resolving existing loops to adding a new task list.
3. Choose a short priority order based on impact and time constraints. Cite the underlying artefact for each status claim.
4. Surface conflicts and missing information without inventing progress. One concise summary should make the next action obvious.
5. Do not change schedules, send messages or reassign work during a status check unless separately authorised.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
