# Style Vocabulary Selection

## When to use
Choose named styles from curated libraries instead of ad-hoc adjective soup.

## Method
1. Translate vague adjectives into named visual references and concrete traits. Style names are not universally superior or single-token representations.
2. Agree a reusable style card covering composition, lighting, palette and exclusions. Preserve traits as well as provider-specific codes.
3. Test representative images on the selected backend. Prompt ordering and code behaviour are model-dependent.
4. Keep one primary visual direction per image and record approved changes before altering a series.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
