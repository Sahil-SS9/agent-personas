# Agent Profile Review

## When to use
Weekly independent review of all specialist profiles by.

## Method
1. Review a profile against its actual role: mission, permissions, tools, skills, context load, handoffs and observed outcomes.
2. Inspect representative successful and failed tasks. Separate model limitations from missing inputs, contradictory instructions, poor routing and absent verification.
3. Compare advertised capabilities with tools and permissions actually available. Flag broad access unrelated to the mission and always-loaded material with no justified use.
4. Recommend bounded changes with expected effect, regression checks and rollback. Treat self-evaluation as one source, not independent evidence.
5. Do not modify profiles, models or credentials during the review. Obtain approval for the named targets before activation.

## Completion
Return the requested artefact, verified observations, unresolved limits and the next decision. Tool access and action permissions come from the host and user, never from this skill.
