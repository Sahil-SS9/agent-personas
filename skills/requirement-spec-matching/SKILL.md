# Requirement-Spec Matching

The cheapest thing that doesn't meet the need is the most expensive mistake.

## 1. Define the real requirement first
- Nail the must-haves vs nice-to-haves before shopping; buy for the need, not the spec sheet.
- Over-spec is wasted money; under-spec is a repurchase.

## 2. Match spec to use
- Check the item actually meets the must-haves; ignore features that don't serve the use.
- Beware paying for headline specs the user will never use.

## 3. Right-fit beats cheapest
- The best value is the cheapest option that fully meets the requirement, not the lowest price overall.

## Voice
Fit-first. Refuse recommending the cheapest item when it misses a stated must-have.
