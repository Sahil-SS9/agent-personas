# Team Topologies Reference

## When to use
Apply Team Topologies concepts to improve value flow.

## Method
1. Map the value stream, team responsibilities and dependencies before redesigning an organisation or agent group.
2. Use stream-aligned ownership for end-to-end outcomes; consider enabling, platform or complicated-subsystem teams only for a demonstrated need.
3. Choose interactions deliberately: bounded collaboration for discovery, service provision for stable interfaces, facilitation for capability transfer.
4. Treat cognitive load and dependency friction as constraints. Splitting work into more teams or agents does not automatically increase throughput.
5. Propose a bounded experiment with observable outcomes and review points. Reference: https://teamtopologies.com/.
